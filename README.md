## 🚀 Getting Started

### Prerequisites
You will need a C++ compiler installed on your system (such as GCC/`g++` for Linux/macOS or MinGW for Windows).

### Compilation & Execution
To build and run the projects, use the following sequence in your terminal:

```bash
# 1. Navigate to the assignment directory
cd asgn1

# 2. Compile the source code
g++ Assign1S11231541.cpp -o tax_calculator

# 3. Run the executable
# For Linux/macOS:
./tax_calculator

# For Windows:
tax_calculator.exe

```

> [!IMPORTANT]
> **For Assignment 2:** Ensure that the input file `studentmarks.txt` is located in the same directory as the executable, otherwise the program will not be able to process the data.
