# Tax Calculator - Assignment 1

## Description
This is a C++ program developed for Assignment 1. It functions as a **Tax Calculator** that takes user details such as name, birth year, residence status, gender, and chargeable income to compute the total tax payable. The program applies various tax rates and flat rates depending on the income brackets and the residential status of the user.

## Features
- Validates user input (e.g., birth year, income).
- Calculates the user's age based on the current year.
- Applies different taxation rules and brackets for Residential vs. Non-Residential individuals.
- Provides a detailed breakdown of the tax computation.
