# Student Marks Management System - Assignment 2

## Description
This is a C++ program developed for Assignment 2. It functions as a **Student Marks Management System** that reads student records from a file, processes their academic marks across multiple subjects (Math, Science, English), and generates organized reports. The program uses structures and arrays to manipulate data in memory.

## Features
- **File Input:** Reads student data (ID, Name, and subject marks) from an external text file (`studentmarks.txt`).
- **Data Processing:** Calculates the total marks for each student.
- **Search Functionality:** Allows users to search for a specific student's record using their Student ID.
- **Sorting:** Sorts the student records based on their total marks.
- **Display Records:** Displays all current student records in the console.
- **File Output:** Generates and writes a summary report to an output text file.
